Cookie & Storage Policy

Last updated: 8 October 2026

Cookies

JARVIS does not set advertising or analytics cookies. The view counter stores no persistent visitor identifier. If you press the appreciation control, a random first-party value is saved in local storage to remember that browser's progress and enforce the 20-press limit.

Functional local storage

The app stores conversation history and appreciation progress in this browser. The OpenRouter API key is never written to local storage or session storage; it remains in page memory and is cleared when the page reloads, closes, or disconnects.

Consent banner

No optional tracking is currently loaded, so a tracking-consent banner is not shown. If advertising, analytics, or non-essential embeds are added, they must remain blocked until any required consent is obtained.
