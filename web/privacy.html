Privacy Policy

Last updated: 28 September 2026

What the web app processes

JARVIS processes the prompt you submit, the OpenRouter API key you provide, model replies, and optional browser speech input. Prompts and the API key are sent directly from your browser to OpenRouter, which may pass prompts to the selected model provider. Review their policies before use.

Storage on your device

If “Remember on this device” is enabled, the API key and chat history are stored in this browser. Disable that option on shared devices or use Disconnect to clear the saved connection. The site operator does not receive the key or chat history through a project server.

Anonymous counters

A visit and explicit appreciation presses are counted by a shared service. It immediately converts network and browser request data into a salted one-way identifier and stores only that identifier, the site name, counts, and timestamps. It uses no advertising cookies or browser identifier. Global Privacy Control or Do Not Track prevents the passive visit record.

Contact and rights

For access, correction, erasure, consent withdrawal, or a privacy grievance concerning data controlled by this project, email kansagara.dwij@gmail.com. OpenRouter and model providers handle requests concerning data they control under their own policies.
