Privacy Policy

Last updated: 8 October 2026

What the web app processes

JARVIS processes the prompt you submit, the OpenRouter API key you provide, model replies, and optional browser speech input. Prompts and the API key are sent directly from your browser to OpenRouter, which may pass prompts to the selected model provider. Review their policies before use.

Storage on your device

The API key remains only in page memory and is cleared when you reload, close, or disconnect the tab. Conversation history is stored in this browser until you start a new chat or clear site data. The site operator does not receive the key or chat history through a project server.

Anonymous counters

Each page load adds one aggregate view without saving a persistent visitor identifier. If you press the appreciation control, the browser creates a random value for this site and saves it in local storage so it can remember your progress and enforce the 20-press limit. The service stores only salted one-way identifiers, the site name, counts, short-lived rate-limit records, and timestamps. Global Privacy Control or Do Not Track prevents the passive view record.

Contact and rights

For access, correction, erasure, consent withdrawal, or a privacy grievance concerning data controlled by this project, email kansagara.dwij@gmail.com. OpenRouter and model providers handle requests concerning data they control under their own policies.
